# Aristotle eNuminous

[Open the interactive catalog dashboard](index.html) for a searchable guide to the laws, axioms, hypotheses, principles, and theorems listed across the eNuminous repositories.

The dashboard includes the full 813-entry Lean theorem/lemma register and explains the evidence limits recorded in the source catalog. Listing a claim does not establish that it is true; the source audit says the Lean projects were not rebuilt for that catalog.
